# Cats

Cats are independent but still need daily play, a clean litter box, and regular vet care.

## Essentials

- **Litter box:** one per cat plus one extra, scooped daily.
- **Play:** two 10–15 minute sessions a day to prevent boredom.
- **Scratching:** provide a sturdy scratching post.
- **Diet:** cats are obligate carnivores — see [Nutrition](./nutrition.md).
- **Vaccines:** see the cat schedule in [Vaccinations](./vaccinations.md).

## Indoor vs outdoor

Indoor cats generally live longer and avoid traffic, fights, and parasites.

Long-haired breeds need more [grooming](./grooming.md). Changes in litter habits are a key item in [Health signs](./health-signs.md).
